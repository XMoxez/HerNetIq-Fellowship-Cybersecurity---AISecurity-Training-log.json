# Cyber security and AI Security Training — HerNetIq Fellowship

I am a fellow in the HerNetIq AI Security Fellowship, a four-month training programme focused on developing practical skills in securing AI systems and applications.

During the fellowship, I worked on practical security investigations involving cloud infrastructure, AI model security, application and API security, Retrieval-Augmented Generation (RAG), AI agent security, and access control.

Through hands-on security labs, I learned to identify vulnerabilities, investigate security incidents, assess risks, implement defensive controls, and recommend remediation measures to protect AI systems against potential attacks.

My goal is to apply these skills to help organisations build safer, more reliable, and secure AI applications.
